
Dados do trabalho

Esta pasta contém os conjuntos de dados utilizados nas análises do estudo. 
Os arquivos estão organizados conforme a origem e a finalidade analítica.

#### DadosSIM_Homicidios_Femininos

Base de dados proveniente do Sistema de Informações sobre Mortalidade (SIM), 
contendo registros de homicídios femininos.
Este arquivo é utilizado para a análise descritiva e exploratória dos óbitos, 
incluindo distribuição por idade, território e características gerais das vítimas.

#### projecoes_2024_tab1_idade_simples

Tabela de projeções populacionais por idade simples,
utilizada como base de referência demográfica.
Este arquivo é empregado no cálculo de taxas, padronizações e 
comparações populacionais nas análises do trabalho.

Observação: Os dados devem ser utilizados exclusivamente para fins acadêmicos e 
analíticos, respeitando as limitações metodológicas e as fontes oficiais de origem.
