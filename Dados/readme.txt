# Dados do trabalho

Esta pasta reúne os conjuntos de dados utilizados no estudo.

---

## DadosSIM_Homicidios_Femininos

Base de dados extraída do Sistema de Informações sobre Mortalidade (SIM/MS), 
contendo registros de óbitos por homicídio de mulheres.

Filtros aplicados na extração dos dados:

* Sexo: Feminino
* Período: 2020 a 2024
* Causa básica (CID-10): X85 a Y09 (agressões / homicídios)
* Faixa etária: 15 a 64 anos

Fonte: SIM / Ministério da Saúde

---

## projecoes_2024_tab1_idade_simples

Tabela de projeções populacionais por idade simples, utilizada como base de referência demográfica nas análises.

Este arquivo é empregado no cálculo de taxas, padronizações e comparações populacionais, 
sendo compatível com o período analisado na base de homicídios femininos.

Fonte: IBGE -> Projeções Populacionais
Cobertura temporal: anos correspondentes ao período da base de homicídios femininos

---

## populacao_residente_por_RacaCor_2022

Base de dados referente à população residente no Brasil em 2022 por raça/cor e faixa etária.

Faixa etária considerada: 14 anos até 60–64 anos
Fonte: IBGE
